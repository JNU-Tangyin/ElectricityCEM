# CEM 策略向量空间探索

本目录分析 71 户德国家庭分别训练得到的 36 维线性策略向量，关注两个问题：向量是否含有稳定的家庭信号，以及是否存在可复现的分组结构。每户在 seed 0、1、42 下各训练一次；这三次重训可用于描述复现性，但不足以精确估计训练随机性的总体分布。

## 当前结论与限制

- 方差分解的 36 维汇总 ICC 约为 0.212（负方差分量截为 0 后）。这是弱到中等的家庭信号；估计基于每户 3 次重训，精度有限。见 `01_核心诊断/theta_variance_decomposition.py`。
- 多项诊断未发现可稳定复现的大型、明显分离簇。不能据此排除小型或弱分离子群；在 n=71、34 维下，对某些弱效应的检验功效很低。
- 家庭对同簇频率的三个跨 seed 相关为 0.368、0.146、0.027；对应未校正置换 p 值为 0.002、0.030、0.363。三次比较做 Holm 校正后，只有第一对仍显著。因此复现证据不一致，不能概括为“两对显著”。
- bootstrap 零参照中，K=2 的稳定性未超过零参照（第 45 百分位）。K=3 超过固定 K 的零参照，但 K 是根据真实数据筛选后再检验，零参照没有重跑完整选模流程；该结果仅作探索，不能作为确认性聚类证据。

二维嵌入仅用于探索和展示，不是结构检验。少数簇相关分析由观察到的分组引出，属于事后探索；除非脚本和结果明确标注，否则不要把它们视为独立验证。`03_小簇机制/` 中的收益扰动使用有限的历史窗口，不能代替独立测试期上的策略泛化评估。

## 目录

### `00_基础/`：共享代码

| 文件 | 用途 |
|---|---|
| `paths.py`、`paths.R` | 路径与坐标定义 |
| `embedding_common.py` | t-SNE / UMAP 共用读取与绘图 |
| `backtest_common.py` | 策略回测共用观测矩阵与 rollout |

### `01_核心诊断/`：向量信号与几何结构

| 脚本 | 用途 | 注意事项 |
|---|---|---|
| `theta_variance_decomposition.py` | 分解户间与户内方差；估计逐维 ICC | 仅 3 次重训；汇总 36 维 ICC 与逐维结果应区分 |
| `shape_diagnostics.py` | Hopkins、最近邻、Isomap、PCA 与功效模拟 | 功效结论只适用于脚本模拟的备择分布 |
| `pair_coclustering_reproducibility.py` | 比较跨 seed 家庭对同簇频率 | 报告三次比较的 Holm 校正结果 |
| `clusterability_test.R` | 多峰、距离与连续结构诊断 | 含基于 seed 42 少数簇的探索性部分；相关 p 值不作独立确认 |
| `tsne_raw_check.py`、`umap_raw_check.py` | 绘制二维嵌入 | 仅可视化；图上团块不能作为分群证据 |

### `02_聚类框架对照/`：聚类探索与零参照

PAM/Ward、GMM、HDBSCAN 和谱聚类使用不同准则探索分组。它们都作用于同一批数据，不能当成相互独立的重复实验。`null_reference_stability.R` 比较固定 K 的 bootstrap 稳定性与逐维打乱零参照；当前零参照没有重复真实数据上的候选 K 选择流程。

### `03_小簇机制/`：事后探索

`small_cluster_density_gap.py`、`minority_direction.py`、`shape_null_comparison.py`、`tail_direction_validation.py` 和 `perturbation_resolution.py` 检查观察到的小簇、分离方向及收益扰动。这些分析共享同一个数据驱动的小簇假设，不应累计成多份独立证据。`perturbation_resolution.py` 实际使用 3 个不重叠的 72 小时窗口；逐户“可分辨”比例是启发式指标。

## 坐标约定

`00_基础/paths.py` 与 `paths.R` 提供两个坐标函数：

- `dims_geometry()`：34 维，排除 location 与 bias。家庭间距离、聚类和几何分析使用此坐标。单户内 location 特征恒定，策略输出只由 `w_loc × location + bias` 的组合决定，二者拆分不可识别。
- `dims_all()`：36 维。逐坐标统计和执行策略时使用完整向量。

方差分解脚本以全部 36 维计算逐维及汇总 ICC，并以 34 维计算户内/户间距离。标准化与输出空间以各脚本的实际实现为准。

## 路径与结果

Python 默认路径由 `paths.py` 配置。R 脚本通过相对路径加载 `paths.R`，需从对应编号目录运行。各分析目录中的 `results/` 是随代码提供的结果快照；重新运行时，脚本默认写入项目的 `04.results/shape/`。快照和脚本可能来自不同运行批次，引用数字前应核对坐标维度、输入向量、脚本版本及参数。带旧分组名称的图仅作历史记录，不代表有效的聚类结论。
